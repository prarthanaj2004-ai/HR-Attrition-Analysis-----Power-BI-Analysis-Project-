### HR-Attrition-Analysis-----Power-BI-Analysis-Project-
• Analyzed employee data to identify attrition trends and workforce risk factors

•	Performed data cleaning and transformation using Power Query for accurate analysis

•	Created DAX measures to calculate attrition rate, active employees, and average income metrics

•	Designed an interactive Power BI dashboard to visualize attrition by department, salary, and experience

•	Identified key drivers of employee attrition to support HR decision-making and retention planning

•	Presented insights through charts, KPIs, and filters for easy stakeholder interpretation
